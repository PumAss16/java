ЗАДАНИЕ 1. Stack trace
------------------------------------------------------------
- Тип: NullPointerException, сообщение указывает на rec.
- Кадр 0 — name (место возникновения), дальше format, render, reproduce.
- Причина — Repo.find возвращает null вместо отсутствия значения.
- Исправление — Optional + orElseThrow, а не null-check в последней строке.

------------------------------------------------------------
ЗАДАНИЕ 2. Checked / unchecked
------------------------------------------------------------
- Неверный аргумент -> unchecked ValidationException.
- Файл -> checked NoSuchFileException.
- Нарушение состояния -> unchecked IllegalStateException.
- Сеть -> checked ConnectException (восстановим повтором).
- Конфигурация -> unchecked NumberFormatException.
- Память -> Error OutOfMemoryError.
- Импорт -> checked CourseImportException.
- Не найдено -> значение Optional.empty.
- Прерывание -> checked InterruptedException (восстановить флаг).
- Баг -> unchecked NullPointerException.

ЗАДАНИЕ 3. Своё исключение
------------------------------------------------------------
- Атрибуты: studentId, courseId, reason.
- Cause сохраняется: super(message, cause).
- message/toString НЕ содержат studentId (PII).
- code() -> reason.code() -> CH-2001..CH-2006.

------------------------------------------------------------
ЗАДАНИЕ 4. try-catch-finally
------------------------------------------------------------
- return в try: try -> finally, значение из try.
- throw в try: try -> catch -> finally.
- return в finally: перекрывает значение из try и СКРЫВАЕТ исключение.
- throw из finally: ЗАМЕНЯЕТ основное исключение.
- Suppressed есть ТОЛЬКО у try-with-resources. Из finally возвращать нельзя.

------------------------------------------------------------
ЗАДАНИЕ 5. Try-with-resources
------------------------------------------------------------
- Порядок: open -> use -> close. close всегда.
- Падают use и close -> основное из use, close в getSuppressed().
- Падает только close -> close основное.
- Два ресурса -> закрываются в обратном порядке, suppressed в порядке закрытия.

ЗАДАНИЕ 15. Граница ошибок CourseHub
------------------------------------------------------------
- Domain/баг -> unchecked, наружу, не в ответ.
- Ожидаемый отказ -> checked, CH-2xxx / CH-3001.
- Инфраструктура -> unchecked InfrastructureException, CH-4001, cause.
- Отсутствие значения -> Optional.
- CourseParser — ничего.
- CourseImporter — NumberFormatException/ValidationException/IOException.
- EnrollmentService — ничего.
- CourseHub — три ожидаемых типа.
- catch (Exception) запрещён: превратит баг в отказ, спрячет дефект,
  смешает бизнес и инфраструктуру, поймает InterruptedException без флага.

------------------------------------------------------------
ОПРЕДЕЛЕНИЯ (минимум)
------------------------------------------------------------
- Checked — наследник Exception, не RuntimeException; компилятор требует обработки.
- Unchecked — RuntimeException; компилятор не требует.
- Error — невосстановимое, не ловим.
- Suppressed — подавленное исключение, только у try-with-resources.
- AAA — Arrange, Act, Assert.
- Граничные значения — min-1, min, max, max+1.
- Don't care — условие, не влияющее на исход при данном правиле.
- Хрупкий тест — зависит от порядка, static state, директории, точного toString.
- PII — персональные данные, не должны попадать в message/toString.
